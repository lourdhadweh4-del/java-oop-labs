# Java OOP Labs
This repository contains Java Object-Oriented Programming (OOP) lab exercises completed as part of my Computer Science coursework.

## Concepts Covered
- Classes and objects
- Object-Oriented Programming (OOP)
- Methods
- Constructors
- Encapsulation
- Inheritance basics
- Problem solving using Java

## Tools Used
- Java
- IntelliJ IDEA

## Purpose
To practice implementing object-oriented programming concepts and strengthen understanding of how classes and objects interact in Java.
These lab exercises helped build a strong foundation for more advanced programming topics such as data structures and software design.
